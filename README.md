# THIS GAME HATES U 💀

**An interactive game that absolutely does not want you to win.**

## 🎮 About the Game

THIS GAME HATES U is a troll-filled game built entirely in Google Slides. It features 10 levels of puzzles, deceptive choices, unexpected twists, and hilarious traps designed to keep players guessing.

Every button might be a trick. Every decision matters. And just when you think you've won… the game has one last surprise for you.

## 🕹️ How to Play

1. Open the game using the link below.
2. Start the presentation and play in Present mode.
3. Click the buttons to make choices and progress through the levels.
4. Solve puzzles, avoid traps, and try to reach the ending.
5. Don't trust everything the game tells you!

## ✨ Features

- 10 levels of interactive gameplay
- Tricky puzzles and misleading choices
- Funny outcomes and unexpected twists
- Multiple decision paths
- A surprise ending
